# 🏥 Lifelink-AI
### An AI-Driven Smart Organ Matching and Transportation Decision Support System

## 📖 About the Project

Lifelink-AI is a smart healthcare web application that helps hospitals and doctors find the most suitable organ donor for a patient using Artificial Intelligence (AI) and Machine Learning (ML). The system compares donor and recipient medical information, recommends the best donor with an AI-generated compatibility score, explains the reason behind the recommendation using Explainable AI (XAI), and suggests the fastest transportation route between hospitals for safe organ delivery. The final transplant decision is always made by the doctor. :contentReference[oaicite:0]{index=0}

## 🎯 Project Objectives

- Develop an AI-based organ matching system.
- Improve donor-recipient matching accuracy using Machine Learning.
- Help doctors make faster and better decisions with AI recommendations.
- Provide transparent AI predictions using Explainable AI (SHAP).
- Optimize organ transportation using the shortest and fastest route.
- Improve the overall organ transplantation process. :contentReference[oaicite:1]{index=1}

## 🔄 Project Workflow

1. User registers as Donor, Recipient, Doctor, Hospital, or Admin.
2. Donors upload organ and medical information.
3. Recipients submit organ requests.
4. AI compares donor and recipient data.
5. System calculates compatibility scores and ranks donors.
6. Explainable AI shows why a donor is recommended.
7. Doctor reviews and approves the recommendation.
8. Google Maps finds the fastest transportation route.
9. Organ is transported to the recipient hospital.
10. Reports and notifications are generated. :contentReference[oaicite:5]{index=5}
